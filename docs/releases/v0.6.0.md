# KRYPT v0.6.0

KRYPT v0.6.0 is the first unified all-platform release.

## Downloads

Choose the installer for your platform:

- **Android:** `KRYPT-0.6.0-android.apk`
- **iPhone/iPad:** `KRYPT-0.6.0-ios-signed.ipa` when Apple signing is configured, otherwise `KRYPT-0.6.0-ios-unsigned.ipa`
- **Windows x64:** `KRYPT-0.6.0-win-x64.exe`
- **Linux x64:** `KRYPT-0.6.0-linux-x86_64.AppImage`
- **Debian/Ubuntu x64:** `KRYPT-0.6.0-linux-amd64.deb`
- **macOS Intel:** `KRYPT-0.6.0-mac-x64.dmg`
- **macOS Apple Silicon:** `KRYPT-0.6.0-mac-arm64.dmg`

The full `CHANGELOG.md` is attached to this release.

## Highlights

- Mobile-first Android and iOS packages.
- Windows, Linux, and macOS desktop installers.
- Shared-server mode so separate devices can connect to the same KRYPT backend.
- Revocable sessions and device management.
- Encrypted DMs, groups, images, replies, reactions, typing, and presence.
- Open-source MIT license.

## Signing

Android is debug-signed. The iOS package is only device-installable when valid Apple signing credentials are configured in GitHub Actions. Desktop packages are currently unsigned, so Windows SmartScreen and macOS Gatekeeper may warn on first launch.

## Security

KRYPT currently uses an MVP NaCl-based E2EE layer. It has not been independently audited and is not yet Signal/MLS-equivalent.
